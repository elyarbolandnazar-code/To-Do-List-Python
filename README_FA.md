📝 فهرست کارها — Python

یک برنامهٔ فهرست کارهای روزانه (To-Do List) مبتنی بر خط فرمان که با زبان Python ساخته شده و برای مدیریت کارها، اولویت‌ها و کارهای انجام‌شده استفاده می‌شود.

این پروژه به‌عنوان یک پروژهٔ عملی برای یادگیری Python ساخته شده و روی استفاده از مفاهیم اصلی Python مانند توابع، لیست‌ها، کار با فایل، جستجو، مرتب‌سازی و اعتبارسنجی ورودی تمرکز دارد.

---

📌 معرفی پروژه

این برنامه به کاربر اجازه می‌دهد کارهای خود را مستقیماً از طریق ترمینال یا کنسول Python ایجاد و مدیریت کند.

هر کار شامل موارد زیر است:

- 📝 متن کار
- 🎯 سطح اولویت
- ✔️ وضعیت انجام‌شدن

کارها به‌صورت خودکار بر اساس اولویت نمایش داده می‌شوند و کارهایی که اولویت یکسان دارند، ترتیب قبلی خود را حفظ می‌کنند.

همچنین برنامه کارها را در یک فایل متنی محلی ذخیره می‌کند تا با اجرای دوبارهٔ برنامه، کارهای قبلی در دسترس باشند.

💾 ذخیره‌سازی اطلاعات

کارها به‌صورت محلی در فایل زیر ذخیره می‌شوند:

tasks.txt

هر خط شامل متن کار و اولویت آن است.

برای مثال:

مطالعه ریاضی|🔴
تمرین Python|🟠
بازی|🟢

هنگام اجرای برنامه، وجود "tasks.txt" بررسی می‌شود و کارهای ذخیره‌شده به‌صورت خودکار بارگذاری می‌شوند.

«فایل "tasks.txt" دادهٔ زمان اجرای برنامه است و از کد اصلی پروژه جداست.»

▶️ اجرای پروژه

پیش‌نیازها

- Python 3.x
- هیچ کتابخانهٔ خارجی Python موردنیاز نیست.

📱 اندروید — Pydroid 3

این پروژه را می‌توان روی گوشی Android با استفاده از Pydroid 3 اجرا کرد.

1. Pydroid 3 را نصب کنید.
2. این مخزن را دانلود یا Clone کنید.
3. فایل "To_Do_list.py" را در Pydroid 3 باز کنید.
4. فایل را اجرا کنید.
5. از کنسول Pydroid 3 برای کار با برنامه استفاده کنید.

فایل "tasks.txt" هنگام ذخیرهٔ کارها به‌صورت خودکار ایجاد می‌شود.

💻 ویندوز

پروژه را می‌توان در Windows با Python 3 به چند روش اجرا کرد.

🐍 روش اول — Python IDLE

1. Python 3.x را نصب کنید.
2. IDLE (Python) را باز کنید.
3. از منوی File → Open استفاده کنید.
4. فایل "To_Do_list.py" را باز کنید.
5. کلید F5 را بزنید یا از Run → Run Module استفاده کنید.
6. برنامه در IDLE Shell اجرا می‌شود.

⌨️ روش دوم — Command Prompt

1. Python 3.x را نصب کنید.
2. Command Prompt را باز کنید.
3. وارد پوشهٔ پروژه شوید.
4. دستور زیر را اجرا کنید:

python To_Do_list.py

اگر دستور "python" شناسایی نشد، این دستور را امتحان کنید:

py To_Do_list.py

💻 روش سوم — PowerShell

1. Python 3.x را نصب کنید.
2. PowerShell را باز کنید.
3. وارد پوشهٔ پروژه شوید.
4. دستور زیر را اجرا کنید:

python To_Do_list.py

اگر دستور "python" شناسایی نشد، این دستور را امتحان کنید:

py To_Do_list.py

بسته به روش انتخاب‌شده، برنامه در IDLE Shell، Command Prompt یا PowerShell اجرا می‌شود.

فایل "tasks.txt" هنگام ذخیرهٔ کارها به‌صورت خودکار ایجاد می‌شود.

🔄 نحوهٔ عملکرد

کارها در یک لیست Python ذخیره می‌شوند.

هر کار به شکل زیر نمایش داده می‌شود:

[task_text, priority]

برای مثال:

["Study mathematics", "🔴"]

هنگام نمایش کارها، برنامه یک نمای مرتب‌شده بر اساس اولویت ایجاد می‌کند.

این نمای مرتب‌شده هنگام انتخاب کار برای عملیات‌هایی مانند موارد زیر استفاده می‌شود:

- ویرایش
- حذف
- علامت‌گذاری به‌عنوان انجام‌شده

به این ترتیب، شماره‌ای که به کاربر نمایش داده می‌شود حتی پس از مرتب‌سازی بر اساس اولویت، به کار درست اشاره می‌کند.

🔍 جستجو

قابلیت جستجو متن واردشده را در نام کارها جستجو می‌کند.

جستجوی حروف انگلیسی بدون حساسیت به بزرگی و کوچکی حروف انجام می‌شود.

برای مثال:

Python

می‌تواند موارد زیر را پیدا کند:

Practice Python

و:

practice python

اگر هیچ کار مطابقی پیدا نشود، برنامه به کاربر اطلاع می‌دهد.
