📝 To-Do List — Python

A command-line To-Do List application built with Python for managing daily tasks, priorities, and completed work.

This project was developed as a practical Python learning project, with a focus on building a complete application using core Python concepts such as functions, lists, file handling, searching, sorting, and input validation.

---

📌 Project Overview

The application allows users to create and manage tasks directly from the terminal or Python console.

Each task has:

- 📝 Task text
- 🎯 Priority level
- ✔️ Completion status

Tasks are automatically displayed according to their priority, while tasks with the same priority maintain their existing order.

The application also saves tasks to a local text file so that they remain available when the program is started again.

✨ Features

- ➕ Add new tasks
- 📋 Display tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✔️ Mark tasks as completed
- 🔎 Search tasks
- 💾 Save tasks to a local file
- 📂 Load saved tasks when the program starts
- 🔴🟠🟢 Assign task priorities
- 📊 Sort tasks by priority
- 🔢 Accept English and Persian digits for menu choices and task selection
- 🔤 Case-insensitive task searching

---

🎯 Priority System

Each task can have one of three priority levels:

Priority| Symbol
High| 🔴
Normal| 🟠
Low| 🟢

Tasks are displayed in this order:

🔴 High → 🟠 Normal → 🟢 Low

Python's stable sorting behavior means that tasks with the same priority maintain their previous relative order.

---

💾 Data Storage

Tasks are stored locally in:

tasks.txt

Each line contains the task text and its priority.

Example:

Study mathematics|🔴
Practice Python|🟠
Play a game|🟢

When the program starts, it automatically checks for "tasks.txt" and loads previously saved tasks.

«"tasks.txt" is runtime data generated by the application and is separate from the main source code.»

▶️ Running the Project

Requirements

- Python 3.x
- No external Python packages are required.

📱 Android — Pydroid 3

The project can be run on an Android phone using Pydroid 3.

1. Install Pydroid 3.
2. Download or clone this repository.
3. Open "To_Do_list.py" in Pydroid 3.
4. Run the file.
5. Use the Pydroid 3 console to interact with the application.

The "tasks.txt" file is created automatically when tasks are saved.

💻 Windows

The project can be run on Windows using Python 3 in several ways.

🐍 Method 1 — Python IDLE

1. Install Python 3.x.
2. Open IDLE (Python).
3. Select File → Open.
4. Open "To_Do_list.py".
5. Press F5 or select Run → Run Module.
6. The program will run in the IDLE Shell.

⌨️ Method 2 — Command Prompt

1. Install Python 3.x.
2. Open Command Prompt.
3. Navigate to the project folder.
4. Run:

python To_Do_list.py

If "python" is not recognized, try:

py To_Do_list.py

💻 Method 3 — PowerShell

1. Install Python 3.x.
2. Open PowerShell.
3. Navigate to the project folder.
4. Run:

python To_Do_list.py

If "python" is not recognized, try:

py To_Do_list.py

Depending on the method used, the application runs in the IDLE Shell, Command Prompt, or PowerShell.

The "tasks.txt" file is created automatically when tasks are saved.

🔄 How It Works

Tasks are stored in a Python list.

Each task is represented as:

[task_text, priority]

For example:

["Study mathematics", "🔴"]

When tasks are displayed, the program creates a priority-sorted view of the task list.

This sorted view is used when the user selects a task for operations such as:

- Editing
- Deleting
- Marking a task as completed

This ensures that the number displayed to the user continues to refer to the correct task even after priority sorting.

---

🔍 Search

The search feature looks for the entered text inside task names.

Searching is case-insensitive for English text.

For example:

Python

can match:

Practice Python

and:

practice python

If no matching task is found, the application informs the user.
